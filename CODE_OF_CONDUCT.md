# 📜 Contributor Covenant Code of Conduct (J.A.R.V.I.S. OS Agent)

## 🧠 Our Pledge

We, as contributors and maintainers of the **Jarvis-OS-Agent**, pledge to make participation in our project a **harassment-free, respectful, and empowering experience** for everyone—regardless of age, body size, disability, ethnicity, gender identity, level of experience, nationality, personal appearance, race, religion, or sexual identity.

We are building an **Autonomous AI Agent** that interacts with real hardware and operating systems. Therefore, we hold ourselves to a higher standard of **trust, safety, and technical responsibility**.

---

## 🚦 Our Standards (Jarvis-Specific Code)

### ✅ Positive Behaviors (What we encourage)
- **Constructive Criticism:** Help others improve their code with kindness and clear logic.
- **Responsible AI Use:** Always consider the security implications of running AI-generated system commands (terminal, ADB, file modifications).
- **Transparency:** When reporting bugs, clearly describe how to reproduce them, especially if they involve system-level commands.
- **Collaboration:** Openly share knowledge and help newcomers understand the complex architecture of Jarvis (Dual-Engine, LTM, Hybrid RAG).

### ❌ Negative Behaviors (Strictly Prohibited)
- **Toxic Communication:** No insults, personal attacks, or derogatory language.
- **Malicious Code:** **Zero Tolerance** for submitting code that attempts to delete system files, encrypt data, or bypass security protocols (e.g., `os.system("rm -rf")`).
- **Privacy Invasion:** Do not share API keys, environment variables, or personal data of other contributors in public issues.
- **Spam PRs:** Opening empty or auto-generated PRs without meaningful changes.

---

## 🛡️ Our Enforcement Responsibilities

As the **Project Maintainer** (Kaif Ansari), I (or any core maintainer) have the right to:

1. **Remove, edit, or reject** contributions (comments, commits, code, issues) that do not align with this Code of Conduct.
2. **Ban temporarily or permanently** any contributor whose behavior is inappropriate, threatening, or harmful to the project or its community.

All enforcement actions will be taken with **fairness and transparency**. The maintainer is obligated to maintain the confidentiality of the reporter.

---

## 🗺️ Scope

This Code of Conduct applies:

- **Within project spaces** (GitHub issues, pull requests, discussions, wiki).
- **In public spaces** (Discord, X/Twitter, LinkedIn) when an individual represents the Jarvis-OS-Agent project or its community.
